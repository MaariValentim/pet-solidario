    Sobre o projeto

    Informação clara aproxima quem quer ajudar.

    O PetSolidário é um MVP acadêmico para reunir campanhas de proteção animal, suas necessidades e formas oficiais de contato. A plataforma não processa pagamentos; qualquer contribuição é feita diretamente com a instituição.

    Antes de contribuir, confirme as informações e os canais de doação diretamente com a instituição.

    PetSolidário é um MVP acadêmico desenvolvido para facilitar o acesso às campanhas.
